# Noise-Resilient ECG Signal Processing & Real-Time Heart-Rate Monitoring Platform

An educational, rule-based prototype for end-to-end ECG signal processing, robust QRS detection, and simulated real-time heart-rate monitoring under adverse noise conditions. **This project is not a medical device and should not be used for clinical diagnosis.**

## Prerequisites
- **Python**: 3.12 or higher
- **OS**: Linux, macOS, or Windows (WSL recommended)
- **Virtual Environment**: Recommended (e.g., `venv`, `uv`, or `conda`)

## Installation

1. **Clone the repository and enter the directory:**
   ```bash
   git clone <repository-url>
   cd ecg-monitor
   ```

2. **Create and activate a virtual environment (optional but recommended):**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

3. **Install the project with development dependencies:**
   ```bash
   pip install -e ".[dev]"
   ```

## Running the Test Suite

The project maintains high test coverage. To execute the test suite (both unit and integration tests):

```bash
pytest -m "integration or not integration"
```

To strictly run fast unit tests (skipping integration tests that require dataset files):
```bash
pytest
```

## Running the Streamlit Dashboard

To launch the interactive dashboard (Phase 14) for exploring datasets, running experiments, and simulating real-time streams:

```bash
streamlit run app/main.py
```
*The dashboard will start locally. Open your browser and navigate to the URL provided in the terminal (usually http://localhost:8501). You should see the "Project Overview" page first.*

## Running Experiments (CLI)

The Phase 11 experimental runner executes robust pipeline comparisons and noise-injection sweeps. The scripts are located in the `experiments/` directory.

To run the Noise Robustness Sweep (Experiment 1):
```bash
python experiments/run_exp1_noise.py
```
*Expected Output: Logs to standard output detailing the execution over records `100`, `101`, and `105`. A consolidated CSV results file will be generated at `results/exp1_noise_robustness.csv`.*

To run the Pipeline Comparison (Experiment 2):
```bash
python experiments/run_exp2_pipeline.py
```

To run the Detector Benchmark (Experiment 3):
```bash
python experiments/run_exp3_detectors.py
```

## Generating Reports

Full session reports (PDF, CSV, and JSON metadata) can be generated by executing a full pipeline experiment. The easiest way to do this is via the **Experiment Runner** tab in the Streamlit dashboard:
1. Open the dashboard (`streamlit run app/main.py`).
2. Navigate to the **Experiment Runner** page.
3. Select a record, inject desired artifacts (e.g., baseline wander, motion), and click **Run Pipeline & Export Report**.
4. *Expected Output*: The dashboard will report success, and the output files will land in a newly timestamped directory under `results/exp_<record_id>_<timestamp>/`.

## Known Limitations

- **MIT-BIH Database Dependency**: Testing and execution primarily rely on the MIT-BIH Arrhythmia Database. The loader currently hardcodes the `.atr` extension, which requires a minor extension to support non-MIT-BIH databases (flagged in `PROJECT_STATE.md`).
- **PhysioNet 403 Forbidden Error**: Automated HTTP downloads from PhysioNet occasionally fail with `403 Forbidden` limits. As a workaround, the project caches required records (`100`, `101`, `105`) in the local `data/` directory.
- **Rule-Based Prototype**: The alert engine relies on configurable, rule-based thresholds rather than machine learning models. It issues "candidate alerts" strictly for educational and pipeline validation purposes.
